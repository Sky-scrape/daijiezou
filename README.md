# 《带节奏》Demo

> 一个**可被操纵的 AI 舆论生态**模拟器。你以庄家的身份进入它,亲手把舆论做成资金。
> 「知乎黑客松 2026 · 校园新锐季」参赛原型(方案 A+B 定稿版)。

## 运行

无依赖、无构建。直接双击 `index.html` 离线可玩;`node server.js`(默认 8788 端口)可激活知乎能力接入。

- 普通模式:`index.html`(默认入口,完整可交互游玩)
- 自动演示模式:`index.html?autoplay=1` 打开即由内置策略自动跑完一局,直达结局复盘页(适合录屏/快速展示);加 `&fast=1` 倍速。自动演示走完整操盘弧线(吸筹→拉抬→高位出货→落袋),headless 自测 100% 好结局。
- 可选 LLM 文本层:启动 server 前设置 `LLM_API_KEY`(可选 `LLM_API_BASE`,默认智谱 GLM 的 OpenAI 兼容端点;`LLM_MODEL`,默认 `glm-4-flash`),水军帖/写手软文/大V看多帖即由 LLM 生成;未配置或调用失败时毫秒级回退内置模板池,游戏永不中断。

## 玩法一句话

你是虚构上市公司**星阑科技(888217)**的暗盘主力,15 个回合内把 3000 万股筹码尽可能换成现金离场。第一课:**你没法直接卖**——每一笔卖出都砸价,买盘池深度决定你的出场价。买盘池 = f(热度, 散户情绪, 价格位置),而热度和情绪,都藏在右边那个社区里。

## 数值平衡(headless 自测)

`node game.js` 直接跑 300 局自动对局(数值层不依赖 DOM):

```
稳健策略:  81% 落袋为安 + 19% 全身而退,平均净利 +8071 万
激进策略:  100% 锒铛入狱,平均净利 -1090 万(罚没后)
躺平策略:  100% 高位站岗,筹码一分未能套现
```

三种策略原型对应三种命运,push-your-luck 风险真实存在:停牌时继续造势的激进者必被立案。

## 知乎能力接入点(已接入)

实现于 `server.js`(服务端代理+缓存,凭证不落前端)与 `js/zhihu.js`(前端加载器,失败自动降级):

1. **盐言故事语料**(免鉴权免额度):拉真实故事标题做写手软文的风格参照,帖内保留作者归属标注。
2. **热榜背景板**(P1):社区页头部的"现实背景板"滚动条,服务端缓存 30 分钟。
3. **直答问答**:社区里"看盘君"助手可回答新手问题(如"什么是T+1"),问题级缓存 24h。
4. **用户画像 NPC**:知乎登录(OAuth)或演示模式(仅限本机)读取创作/关注画像,生成"以你为原型"的虚构散户 NPC。完整 OAuth 待黑客松报名后配置 App ID/Key;宣传语现成:"AI 读完你的知乎主页,把你自己做成了游戏里被割的韭菜。"公网评审环境(无 OAuth、非本机)自动降级为**虚构示例分身**,分身玩法在任何环境都可演示。

**文本层选型说明**:知乎直答经实测只能做事实问答,会拒绝角色扮演类创作请求(安全策略),故创作类文案走通用 OpenAI 兼容接口(`server.js` 的 `/api/llm/post`,服务端代理+缓存,凭证不落前端);直答继续负责它擅长的"看盘君"新手问答。

所有 API 调用均在服务端完成并缓存;额度耗尽/接口异常时自动回到本 demo 的本地模板池,游戏不中断。部署指引见 `README-DEPLOY.md`。

## 文件结构

```
index.html   页面骨架(开始画面 / 主界面 / 卖出弹窗 / 结局复盘页)
style.css    知乎风浅色样式
game.js      数值模拟层:市场、买盘池、NPC情绪、监管、结局 + headless 自测(node game.js)
ui.js        DOM 表现层:渲染、交互、传导图、疫苗卡、战报复制
server.js    零依赖 Node 服务器:静态托管 + 知乎 API 代理 + 缓存降级(node server.js)
js/zhihu.js  前端接入加载器:探测能力、拉语料/热榜、OAuth 回调、直答问答
```
